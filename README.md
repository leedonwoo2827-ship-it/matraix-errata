# 산물 검수엔진 — MatrAIx 검수단 × 정오표

이미 만든 수험서 산물을 한꺼번에 검수해 **정오표**를 뽑는다. 어느 시험에나 쓴다 — 시험 지식은 `data/pack/<팩>/` 설정에만 있다.

```
setup.bat   한 번만 (이 폴더 안에 .venv) — python 3.11~3.13 · git · claude CLI 로그인
Claude Code 로 이 폴더를 열고 「시작」 → 시험·산물 폴더·검수단을 묻고 data/ 에 팩과 잡을 만든다
run.bat     더블클릭 → 웹앱 http://127.0.0.1:5191   ·   run.bat <단계> → CLI
```

API 키는 쓰지 않는다. 검토는 Claude Code 구독(`claude -p`)으로 간다. 검수단은 [MatrAIx Persona-1M](https://huggingface.co/datasets/MatrAIx2026/MatrAIx_Persona_1M_Public_Release)
에서 뽑는다(코드 [MatrAIx-Persona-8B](https://github.com/MatrAIx-ai/MatrAIx-Persona-8B), MIT — 처음 `panel` 때 `data/engine/` 아래로 받는다).

## 폴더

```
errata/          파이프라인·웹앱·프롬프트
engine/tools/    MatrAIx 검토분석엔진 도구 사본(provider·sample_panel·fetch_persona·unitdir)
pack/_template/  새 시험 팩·잡 틀
data/            깃 제외 — 팩(data/pack)·잡과 산출물(data/jobs)·엔진 작업 폴더·로그
```

## 시작 프롬프트 — Claude Code 로 이 폴더를 열고 그대로 붙여 넣는다

**새 시험 붙이기** (처음 한 번 · Claude 가 묻고 data/ 에 팩과 잡을 만든다)
```
시작. 새 시험 검수를 준비해 줘.
시험: SQLD(SQL 개발자, 한국데이터산업진흥원), 2과목(데이터 모델링의 이해 · SQL 기본과 활용), 50문항 4지선다.
산물 폴더: 문항 책 D:\work\sqld-book · 롱폼 D:\work\sqld-longform · 교재 D:\work\sqld-longform\out\textbook · 쇼츠 없음.
검수진은 DB 실무자·SQL 강사 위주로, 수험생은 비전공 직장인 비중을 크게.
모르는 건 물어보고, 다 정해지면 ingest → panel → 1회차 시험(trial)까지 돌려 줘.
```

**◆ADsP 예 — 처음부터 전체 검수까지** (setup.bat → run.bat 으로 웹앱을 켠 뒤 Claude Code 채팅창에 붙여 넣는다)
```
시작. 새 시험 검수를 처음부터 끝까지 해 줘. (.venv 는 setup.bat 으로 깔았고, 웹앱은 run.bat 으로 켜 두었다)

[시험]
- ADsP(데이터분석 준전문가, 한국데이터산업진흥원 K-data 주관) 필기. 팩·잡 이름은 adsp.
- 1과목 데이터 이해(데이터의 이해·데이터의 가치와 미래·가치 창조를 위한 데이터 사이언스와 전략 인사이트)
- 2과목 데이터 분석 기획(데이터 분석 기획의 이해·분석 마스터 플랜)
- 3과목 데이터 분석(R기초와 데이터 마트·통계분석·정형 데이터 마이닝)
- 50문항(10·10·30), 4지선다.

[산물 폴더 — 읽기만]
- 문항 책: <문항 책 폴더>  (요약노트 03/summary_understanding·planning·analysis.html = 1·2·3과목)
- 롱폼 잡: <롱폼 잡 폴더>
- 교재: <교재 폴더>  (단행본 PDF 를 새로 만들었으면 그 폴더로)
- 쇼츠: <쇼츠 폴더>  (과목 폴더 ADsP-*)

[검수단 — 검수진 4 + 수험생 6, 씨앗 20261008]
- 공통: 데이터과학·통계·데이터분석 중 하나는 아는 사람, 한국어 Native/Fluent(수험생 포함)
- 검수진 E1 통계·근거(통계 Expert/Proficient), E2 데이터분석 실무(데이터과학 Expert/Proficient, 실무자),
  E3 강의·출제(교육자), E4 교정·사실확인(사실확인·교정 Master/Advanced). 25~64세, 경력 6년 이상 우대, 동아시아 우대.
- 수험생 상 2(데이터분석 Master/Advanced) · 중 2(Intermediate, 통계 용어에서 막힘) · 하 2(Beginner/None, 처음 공부).

[규칙]
- 금지어: 「기출」→「모의고사」(자체 집필 문항), 「{원본링크}」·TODO·TBD 는 지움.
- 쇼츠 라벨: 맞음 ADsP·데이터분석준전문가 / 틀림 빅데이터분석기사·빅분기·정보처리기사·SQLD·컴활·컴퓨터활용능력.
- 검토 순서 Q→L→B→S→T, 1회차 시험 범위 Q:m01-,L:L01:,B:01:01,S:understanding:01,T:q1-01.

[진행]
1. 검수단 조건은 표로 보여 주고 내가 확인하면 뽑아 줘. 패널명부도 보여 줘.
2. ingest → panel → 1회차 시험(trial)으로 엑셀·HTML 형식을 확인해서 보여 줘.
3. 형식에 문제가 없으면 내 답을 기다리지 말고 바로 전체 실행(all)을 백그라운드로 돌려 줘.
   (검토 282배치 · 재검증 · 정오표 · 검수표까지, 사용 한도에 걸리면 기다렸다 이어서. 진행은 웹앱 ③ 진행에서 본다)
4. 끝나면 엑셀 「요약」 시트, 07_이력.md 맨 위(안 끝난 것), 진행표(검수기록.xlsx)를 보고해 줘.
   지적은 확정하지 말고, 판정 열은 비워 둬.
```
전체 실행은 ◆ADsP 기준 4~5시간. 도는 동안 검은 서버 창과 VSCode 를 닫지 않는다(끊기면 웹앱 「전체 실행 (무인)」이 남은 것부터 잇는다).

```

01_선정       검수진 4(통계·실무·강의·교정) + 수험생 6(상·중·하)          도구 (MatrAIx)
02_기계검사   셀 수 있는 것 — 정답 낭독 대조·원천↔파생·금지어·라벨·판 대조  도구 (무료)
03_검토       검수단이 배치마다 읽고 지적 (문항은 눈가림 재풀이부터)        모델
```

## 사람이 하는 일 — 판정

1. `05_정오표/정오표_내부.xlsx` 의 「정오표」 시트에서 **판정** 열에 `반영`·`보류`·`거절` 을 고른다. 바름(TO BE)을 고쳐 써도 된다.
2. 「웹확인 필요」 시트는 검색 링크를 눌러 직접 확인하고 판정한다.
3. 저장하고 웹앱 **05 정오표**(또는 `run.bat errata`)를 누르면 `정오표_게시.html` 에 반영한 것만 나간다.

다시 돌려도 판정은 사라지지 않는다(`decisions.json` 에 옮겨 두고, 같은 지적은 같은 열쇠 `fid` 로 따라간다).

## 무인 운전

웹앱 **전체 실행** 또는 `run.bat all`.

- 검토 결과는 배치마다 파일로 남는다. 끊겨도 같은 버튼을 다시 누르면 남은 것만 이어서 한다.
- 사용 한도에 걸리면 풀릴 때까지 기다린다(최대 30시간, `job.json` 의 `llm.limit_wait_hours`). 기다리는 동안 PC 절전을 막는다.
- 25배치마다 중간 정오표를 뽑는다.
- **검은 서버 창은 닫지 않는다.** 브라우저는 닫아도 된다.

## 한계

검수단은 가상의 응답자다. 실제 전문가·수험생의 검수를 대체하지 않는다.
「통과」는 셀 수 있는 것만 본 판정이다. "좋은 산물인가" 에는 답하지 않는다.
확정은 사람이 한다.
