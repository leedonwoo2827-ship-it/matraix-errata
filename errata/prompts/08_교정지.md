## 볼 것
- 사실 오류, 정의·공식·수치·예제 계산 오류, 문장 안의 모순, 앞뒤 쪽의 서로 다른 말.
- 오탈자, 띄어쓰기, 용어·표기 흔들림(같은 개념의 다른 표기), 숫자·기호·단위 표기.
- 수험생이 오해할 서술, 시험 범위 밖 서술.
- PDF 글자 뽑기의 줄바꿈·하이픈·머리말·쪽번호는 조판 결과라서 지적하지 않는다(글자만 보고는 쪽 모양을 알 수 없다).

## 두 갈래로 낸다 — `kind`
- `수정` : 틀린 것이 분명하다. `to_be` 에 바로 바꿔 넣을 문구를 쓴다. → 편집자가 정오표(수정 예정)로 모은다.
- `문의` : 저자에게 확인할 것 — 사실 여부가 확실치 않거나, 의도가 둘로 읽히거나, 외부 근거(기관명·연도·통계·법령)가 필요하다.
  `question` 에 저자에게 묻는 한 문장을 쓴다(존댓말, 예: 「…로 보이는데 …가 맞는지 확인 부탁드립니다.」).
  **`to_be` 도 반드시 쓴다** — 저자가 「예」 하면 그대로 바꿔 넣을 제안 문구다. 문의도 잘못 → 바름 형태로 묻는다.

## 규칙
{{require}}
- `page` 는 아래 「== N쪽 ==」 의 N 이다.
- `as_is` 는 그 쪽 본문에서 **글자 그대로 복사**한 문자열이다(8~60자, 한 줄 안에서). 지어내거나 고쳐 쓰지 않는다 — PDF 위에 형광 표시를 하는 열쇠다.
- 문체·취향은 지적하지 않는다. **틀린 것, 서로 어긋나는 것, 오해를 부르는 것**만 낸다.
- 심각도: 상 = 틀린 것을 가르친다 · 중 = 혼동·불일치·범위 · 하 = 오탈자·표기·띄어쓰기.
- 지적이 없는 쪽은 `clean` 에 쪽 번호를 넣는다. **모든 쪽이 findings 또는 clean 에 나와야 한다.**
